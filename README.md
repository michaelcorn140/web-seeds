# Seeds Studio website (static)

Static site, no build step. Open `index.html` or deploy the folder as-is (e.g. Vercel, Netlify, GitHub Pages).

- Font: Open Sauce Sans (SIL Open Font License), self-hosted in `fonts/`.
- Gacha and accounts run in demo mode on a static host: results are not saved. Real accounts need a backend (e.g. Supabase).
- Prices, slot count and most social links are still placeholders.
